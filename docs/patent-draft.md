# 一种基于预定时间滑模与分段增益调度的四旋翼无人机位置跟踪方法

（技术文档，完整版见课程报告 docx/pdf）

## （一）技术领域

本发明属于无人飞行器飞行控制技术领域，具体涉及一种基于预定时间滑模控制与分段增益
调度的四旋翼无人机位置跟踪方法，可用于定点悬停、航点归位与轨迹跟踪。

## （二）背景技术

四旋翼为欠驱动、强耦合非线性系统，工程上普遍采用位置—姿态双环串级结构，性能瓶颈
在外环。现有方法包括 PID、LQR/H∞、反步与动态面、以及滑模变结构控制：传统线性滑模
渐近收敛；终端滑模有限时间收敛但收敛时间依赖初值；预定时间控制使收敛时间上界仅由
设计参数决定，但仍存在时变增益跳变、姿态指令抖振、稳态平滑性与精度难以兼顾、缺少
工程化实现等问题。

## （三）发明内容

目的：解决收敛时间不可预设、姿态指令抖振大、稳态精度与平滑性难以兼顾的问题。

方案（十个步骤）：建立三轴位置模型并装订参数 → 构造误差 → 计算核函数与含延时项的
滑模面 → 计算等效控制力 → 力/力矩分配 → 姿态指令低通滤波 → 内环 PID → 分段切换
判据 → 循环执行 → 输出指标。公式与推导见 `docs/algorithm.md`。

有益效果：收敛时间可预设；姿态指令变化率由 2807 (°)/s 降至 899 (°)/s；1 cm 收敛
时间由 9.51 s 提前至 8.64 s；纯标量运算、可部署于 32 位飞控。
