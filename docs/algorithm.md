# 算法说明

## 1. 被控对象

忽略小角度下的姿态耦合，位置通道解耦为三个二阶子系统：

```
m ẍ = ux − kx ẋ + dx
m ÿ = uy − ky ẏ + dy
m z̈ = uz − m g − kz ż + dz
```

统一写作 `ẍi = fi + gi·ui + δi`，其中 `fx = −kx·ẋ/m`、`fz = −g − kz·ż/m`、
`gi = 1/m`、`δi = di/m`，`|di| ≤ dmax`。

## 2. 预定时间滑模面

```
si = e2,i − ai·e1,i + K(t)·e1,i(t − h),   h = T/3
```

时变增益由周期核函数调制（R1 核）：

```
R1(t) = sin²[π(t − h)/h],  t ∈ [h, 2h)
K(t)  = (2/h)·R1(t)·exp[−2a(t − h)]
```

核函数以 `2h` 为周期，在 `[0, h)` 上取零、在 `[h, 2h)` 上取非零；指数因子用于
抑制延时项在稳态阶段对测量噪声的放大。当 `a = 0` 时退化为 `K(t) = (2/h)R1(t)`。

## 3. 控制律

```
ui = m·[ −(c/2^α)·sig^{2α−1}(si) − (d/2^β)·sig^{2β−1}(si)
         − ρ·sat(si/φ) − fi + ai·e2,i
         − K(t)·e2,i(t − h) − K̇(t)·e1,i(t − h) ]
```

- `sig^γ(s) = |s|^γ·sgn(s)`，`sat(·)` 为饱和函数；
- `c = d = 10/T`，`α ∈ (0.5, 1)`，`β > 1`，`ρ ≥ dmax/m`，`φ = 0.001`。

取 `V = si²/2`，在 `|si| > φ` 上有 `V̇ ≤ −(c/2^α)|si|^{2α} − (d/2^β)|si|^{2β} ≤ 0`，
滑模变量在有限时间内进入边界层，且时间的上界只与 `T、α、β` 有关。

## 4. 力/力矩分配

```
Tc = uz,   φd = arcsin(uy/Tc),   θd = arcsin[ux/(Tc·cos φd)]
```

对 `Tc` 取正下限（1 N），对 `φd、θd` 限幅 ±30°。分配式的物理含义是
`ax = (Tc/m)sin θd`、`ay = (Tc/m)sin φd`、`az = Tc/m − g`，因此悬停点
`Tc = mg` 与重力平衡。

> 早期实现把总推力写成 `f = m(g − uz/m)`，在悬停点推力趋于零，是
> `quadrotor_simulation_results_corrected.mat` 中 z 轴发散的根因。

## 5. 指令滤波与内环

```
φf(k) = αf·φf(k−1) + (1 − αf)·φd(k),  αf = exp(−Δt/τ),  τ = 1/(2π fc)
τj = Kp,j·eφ,j + Ki,j·∫eφ,j dt + Kd,j·ωj,  |∫eφ,j dt| ≤ 2/Ki,j
```

`fc = 5 Hz`，力矩限幅 0.5 N·m；姿态刚体动力学 `Ij·ω̇j = τj − Bj·ωj`。

## 6. 参数整定顺序

1. 由任务时间预算确定 `T`，取 `h = T/3`；
2. 按执行机构带宽确定 `Δt`（本文 1 ms），并留出 `ceil(h/Δt)+10` 的延时缓冲区；
3. 由扰动上界定 `ρ`（留 20 % 裕度），由稳态精度定 `φ`；
4. 由收敛速度定 `c、d`（本文 `10/T`），再微调 `α、β` 抑制超调；
5. 最后整定内环 PID 与指令滤波器 `fc`，`fc` 取内环带宽的 1/5～1/10。

## 7. 分段切换

```
ts = T − 0.495·exp(9 − T) − 0.405
```

`t < ts` 用滑模保证到达，`t ≥ ts` 切换 PID 保持。`T = 9 s` 时 `ts = 8.10 s`。
